# E-Closet 项目进度（2026-09-16）

## Background Removal 与 Closet 顺序（2026-09-30）

- 新增 Next.js Route Handler：`POST /api/remove-background`，由服务端读取 `REMOVE_BG_API_KEY` 并代理 remove.bg，API key 不进入浏览器代码。
- 图片选择后自动生成最大边 2000px 的临时 WebP 传输副本，避开 Vercel Function 请求体限制；IndexedDB 仍保存未经压缩的上传原图。
- remove.bg 透明 WebP 结果写入现有 `processedImage` 字段；处理期间禁用 Save，错误状态提供 Retry。
- Closet 的 Add Item Card 已移动到 `Frame 1` 第一项；空数据库时不再显示 `Your closet is empty...` 提示。
- 本地未配置真实 API key，因此只验证了缺少配置时的安全 503 响应；实际 remove.bg 调用需在 `.env.local` 与 Vercel 环境中配置 `REMOVE_BG_API_KEY` 后验证。

## 功能化实现（2026-09-29）

### 本地数据库与衣物闭环

- 保留 Next.js 16 App Router，并安装 `dexie`、`dexie-react-hooks`、`react-rnd`。
- 建立 `e-closet` IndexedDB，包含 `clothingItems` 与 `outfits` 两张表；首次使用保持空库，不写入演示数据。
- 图片以 Blob 存储并通过可回收 Object URL 显示；本轮仅保存原图，同时保留可选 `processedImage` 字段。
- Item Detail 已实现新增、载入、编辑、删除、文件类型/10 MB 限制、Name、六类 Category 与七色 Tag 单选。
- 删除衣物使用 Dexie transaction，同时从所有 Outfit 中清除相应 piece 引用。

### Closet 与 Outfit Builder

- Closet 已改为实时数据库列表，支持不区分大小写的 Name 搜索、`All + 六类`横向筛选及组合筛选。
- Item Card 显示真实图片、Name、Category 与颜色圆点；补齐 Loading、空库、无结果和数据库错误状态。
- `ADD FROM CLOSET` 已实现四个收起 Tray、六类展开 chips、两列实时衣物列表和连续添加。
- Outfit 画布使用受控 `react-rnd`：支持画布边界、锁比例四角缩放、选中、Front、Back、Duplicate 与 Remove。
- Outfit 保存归一化位置和尺寸；名称可留空并自动使用浏览器本地日期。
- `/outfits/new` 创建记录，`/outfits/[id]` 读取/更新/删除记录，保存后进入 Saved Outfits。

### Saved Outfits、路由与文档

- Saved Outfits 已改为实时数据库记录，并根据 Outfit pieces 与衣物 Blob 动态绘制缩略拼贴，不保存截图。
- Next.js 16 动态路由现在 await `params`，并把真实 `itemId` / `outfitId` 传入页面组件。
- 三个主页面改用同一个底部导航组件，消除导航栏高度差异。
- `TECH_STACK.md` 与 `UXDESIGN.md` 已同步为 Next.js 16、当前路由、Dexie 数据格式和现有交互，不再描述 Vite 迁移或本轮 remove.bg 调用。

## MVP Scope Revision（2026-09-26）

根据反馈，双周 MVP 已收敛为单用户、响应式衣橱网站，并以四个核心视图完成完整用户旅程：

1. Closet
2. Item Detail
3. Outfit Builder
4. Saved Outfits

本轮仅更新项目 Markdown 文档，尚未修改代码、依赖或路由。当前实现仍是早期 Next.js 七页面原型，后续开发阶段需要完成以下迁移：

- 前端迁移到 React + Vite + TypeScript
- 使用响应式 CSS，移除固定手机外壳作为唯一布局
- 使用 `react-rnd` 实现搭配画布拖动与缩放
- 使用 IndexedDB / Dexie 保存衣物、图片和穿搭
- 将 Add New Item 合并为 Item Detail 的 add mode
- 删除 MVP 中的 Outfit Detail 与 Me / Settings
- Saved Outfit 直接重新打开 Outfit Builder
- 通过 Vercel 部署静态 Vite 前端，并使用同一项目中的 Vercel Function 代理背景移除请求

账号、云同步、PWA 和 personal-photo try-on 已明确延期。
